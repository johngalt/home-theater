# Soffit

Will need intake and return ducts for ventilation. Ventilation is a big escape path for sound, so will need to implement some soundproofing considerations here. One important thing will be to run flex+insulated ducting a good distance within the decoupled room. A longer duct will reduce sound transmission. Will want to keep the ducting WITHIN the decoupled room, likely in a soffit.

Good example for soffit construction here (Bigmouth Soffit build - <https://www.avsforum.com/posts/20844513/>)\

# Existing ducts above room

There are existing ducts for the living room and bedroom in the joists above the room. This would be another flanking path for sound transmission up. It may be best to replace this with flexible/insulated ducting and secure it up into the joists.\
